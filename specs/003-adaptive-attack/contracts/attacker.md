# Contract: the attacker model

The model that drives an adaptive attack. One HTTPS call per turn to an OpenAI-compatible endpoint, made with `httpx` — the same shape as [feature 002's judge client](../../002-single-turn-attack/contracts/judge.md), no SDK (research R1, R5). This contract describes behaviour and configuration only; it contains no attack text.

## Configuration

| Setting | Source | Default |
|---|---|---|
| Model | `KESTREL_ATTACKER_MODEL` | `deepseek/deepseek-v3.2` (R1) |
| Key | `KESTREL_ATTACKER_API_KEY`, falling back to `OPENROUTER_API_KEY` | none |
| Endpoint | `KESTREL_ATTACKER_BASE_URL` | `https://openrouter.ai/api/v1` |

With no key, `GET /api/config` reports `attacker.configured: false` and an adaptive run cannot start; the screen says so, the way the judge degrades in feature 002. The key is read from the environment, never stored, never logged (R12).

## What the attacker receives

Only what it needs to produce the next message (Principle IV, R8):

- A standing instruction describing its role — to continue a single-message-at-a-time conversation with the target and work toward the attack goal of the chosen family, within the bounds of plain conversation (no flooding, one message per turn).
- The conversation so far: its own previous messages and the target's masked, cut replies, in order.
- The latest judge note — the one-line "how close" assessment from the previous turn (R6) — as the signal for what to try next.
- The opening message for turn one is the seed drawn from the attack library (feature 002's selection), not generated by the attacker.

It MUST NOT receive the target's auth header values, URL, name, or any other stored setting.

## What the attacker returns

A single plain-text message to send to the target next (Principle VIII: one message, no repetition, no flooding). The message is capped in length; an over-long answer is cut before it is sent. The attacker returns conversational text only — it is not given tools and makes no tool calls.

## Limits

| Limit | Value | Requirement |
|---|---|---|
| Per-call timeout | bounded, no more than what the run's remaining wall-clock allows | FR-011 |
| Message length | a fixed cap, cut before sending | FR-009 |
| Turns | the run's turn cap (default 6) governs how many times the attacker is called | FR-010 |
| Tokens | each call's `usage.total_tokens` counts against the run's token budget | FR-010, R7 |

## Failure

If the attacker model is not configured, cannot be reached, times out, or returns nothing usable, the run ends **unclear** with a reason naming the attacker-model failure and `stopping_condition = attacker_failed`, keeping whatever conversation occurred (FR-016). A failure of the attacker is never presented as the target holding firm.

## Recording

Every adaptive run records the attacker model and version exactly as configured, alongside the judge model and the budgets allowed and used (Principle III, FR-015). The attacker is recorded in addition to the seed's `attacker_source` (`library:<version>`), which still names where the opening came from.
